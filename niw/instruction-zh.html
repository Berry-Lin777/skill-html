01

开始 NIW

作用
告诉 Cursor Agent 你要做 NIW，它才会进入 NIW 区并准备建案。
你做什么
  1. 用 Cursor 打开已下载的 skill 文件夹
  2. 新建 Agent 对话，粘贴下面这句话
发给 Cursor
我已经把这个移民 skill 下载到当前文件夹了。我想准备 NIW（国家利益豁免）材料，请从这一步开始带我做。
02

终端和桌面怎么选

作用
Agent 会问你用哪种界面。两种写出的材料一样，差别只在窗口怎么摆。Cursor 用户默认选「终端」即可。
你做什么
  1. 先看清下面区别
  2. 回复：终端
  3. 系统浏览器会打开 Intake；没有就按 Cursor 里给的本地链接打开
本教程默认

终端模式

Cursor 对话写材料，系统浏览器填 Intake / 表单。两个窗口来回切，不需要额外安装。

可选窗口

桌面模式

OpenNIW 自带 Electron 小程序（optional/desktop/），左右分屏。只改窗口怎么摆，不提高文书质量。

两边材料相同，都写进同一个 niw-case/。演示和日常用 Cursor 时，选终端即可。

发给 Cursor
终端
03

填 Intake：链接 + 基本情况

作用
用链接和基本字段把履历灌进案卷，避免把论文列表整段手打进聊天。
你做什么
  1. 粘贴 Scholar / 主页 / LinkedIn / 其他链接
  2. 上传简历（可选）
  3. 填职位、学位、领域、是否在美
  4. 点 Done
04

回到 Cursor：生成档案并打开对比页

作用
浏览器完成交接后，Cursor Agent 读取 Intake，写出 profile.md，再打开同行对比（Benchmark）。
你做什么
  1. 看到「Now return to your agent」就回到 Cursor 对话
  2. 发一句：网页上我填完了，已经点了 Done
  3. 可按需补充姓名/学位/论文数等（演示案可写假数据）
发给 Cursor
网页上我填完了，已经点了 Done。 补充一下（演示用）：姓名 Alex Rivera；PhD Environmental Data Science，2019；independent consultant；方向 climate risk / coastal flood modeling；论文约 18 篇，引用约 210。
05

看 Benchmark，点 Done

作用
把你的论文/引用放进已批准公开案池里看相对位置；这是校准，不是获批概率。
你做什么
  1. 核对领域、论文数、引用数
  2. 看分布图与百分位
  3. 点 Done — return to the agent
发给 Cursor
对比页我看了，已经点了 Done。
06

生成 Stage I 的评估报告

作用
Cursor Agent 把缺口与三项要件的现状写进 evaluation.md，决定要不要继续冻结 endeavor。
你做什么
  1. 阅读评估摘要
  2. 要继续就回复：继续
发给 Cursor
继续
07

起草并冻结 Proposed Endeavor

作用
后面所有文书都要原句引用这句 endeavor；冻结前改，冻结后尽量别改。
你做什么
  1. 看 Cursor 给的草案
  2. 在选项里选一句（演示选 B）
  3. 确认冻结
提示：Skill 里说的「冻结」就是锁定的意思——这句 endeavor 定下来之后，后面的文书都会照这句原话写，不会再改动。
发给 Cursor
选 B，冻结。
08

收集证据

作用
证据清单就是列出这个案子还缺哪些证明材料（推荐信、获奖证明、媒体报道等），列成一张清单，后面补材料有目标，不会盲找。
你做什么
  1. 回复继续（进入 II·b）
  2. 保存 Cursor 给出的证据清单
09

论文和其他材料查漏补缺

作用
论文数影响对比百分位；means（资金/合作/试点）决定 endeavor 是否“做得到”。没有 LOI 也可以先诚实写「尚未具备」。
你做什么
  1. 按 Agent 要求粘贴论文列表，或选路径 B（无 PDF）
  2. 用几句话说明资金、合作、试点现状
  3. 让它按真实论文数重算 benchmark
发给 Cursor
执行手段（演示）： - 自费独立顾问时间；本地算力 - 计划开源沿海水质/洪水筛选模型 - 县级试点在谈，尚无 LOI / 正式协议 请按论文数=8 重算 benchmark。
10

最终交付第一份正式文书

作用
PES（Proposed Endeavor Statement）是第一份正式文书，用来说明你要做什么、为什么有公共价值、准备怎样执行。它是政策钩子 + 项目计划 + [TODO] 组成的草稿，还不是整包终稿，但已经是可审阅的交付物。
你做什么
  1. 回复：进入 Stage III 起草
  2. 打开 niw-case/documents/pes.md
  3. 先核对 §1–§2，再逐段填 [TODO]
发给 Cursor
进入 Stage III 起草
Final deliverable · 本教程最终交付物
最终交付第一份正式文书
niw-case/documents/pes.md

PES 是申请材料的第一份正式文书，用来把你的 Proposed Endeavor、项目计划、政策依据和执行方式写清楚，下面是预览。后面补事实、改段落，都改这一份 pes.md，不用另开新文档。

注意：它是可审阅的自助草稿（含 [TODO]），不是整包终稿，也不是可直接递交 USCIS 的文件。支持信、Petition Letter、填表属于下一步。

Result · 到这里为止
最终交付第一份正式文书
niw-case/documents/pes.md

前面的 Intake、Benchmark、评估、冻结 endeavor、补证据，都是在为这份 PES 打基础。PES 写清楚了你要做的事、为什么符合国家利益、准备怎样执行，律师和你自己都可以拿它作为后续文书的核心依据。

后续怎么改：直接改 pes.md 里的政策钩子、项目计划、means、[TODO]；endeavor 句子变了，先重新冻结，再让 Cursor 同步改 PES。案卷里其他文件（profile / evaluation / checklist）是支撑材料，不是交付物本身。

围绕 pes.md 修改

  1. 在 Cursor 打开 niw-case/documents/pes.md，直接改正文；或对 Agent 说：「改 PES §2……」「把 §3 第三个项目改成……」
  2. 若要改 endeavor 原句：先冻结新句子，再要求「按新 endeavor 重写 PES」
  3. 论文数 / means 变化：先更新案卷与 benchmark，再让 Agent 把校准结果写回 PES 相关段落

想重跑怎么做

  1. 只重写交付物：同一 niw-case/ 续聊：「从 Stage III 重写 pes.md」
  2. 整案重来：备份并改名旧 niw-case/，新开 Cursor Agent，从步骤 01 重新开始
  3. 换真人材料：Intake 用你自己的链接与事实；把 PES 里所有 [TODO] 换成真实信息后再继续后面阶段
备份示例：mv niw-case niw-case-demo-2026-08-11 然后新开 Cursor Agent，重新说：我想准备 NIW 材料，请从这一步开始带我做。
