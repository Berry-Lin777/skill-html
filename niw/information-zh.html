OpenNIW Petition Suite · Information

用 AI 申请美国身份 · NIW / EB‑1A / O‑1 全流程 Skill

OpenNIW Petition Suite 是一套面向自申请人的美国就业类移民材料工作流：整理个人材料、对照获批案例、起草 NIW / EB‑1A / O‑1 文书，并在浏览器里辅助填表、按官方顺序打包。这不是法律建议，也不是律所服务。

完整走完材料准备流程，目标是帮你显著降低传统律所文书起草成本。

涉及法律判断请咨询持牌移民律师；你对自己签字、递交的材料负全部责任。

Skill 解决的痛点

移民申请的痛点很直接：流程长、成本贵、信息不透明，中间要耗掉大量律师费和时间。这套流程帮你省掉重复劳动和一部分律师费，把时间留给真正该做的事。

步骤一：收集资料，统计评估申请水平（Stage I）

传统流程里，律所要花大量人工时间搜集你的信息、翻你的论文；自己动手办的人对这种反复折腾也不陌生。你只要给一份谷歌学术、领英链接和论文线索，Agent 会尽量在网上做 deep research，把你发表过的论文、所在领域、合作者和机构都整理出来，写成一份档案，并自动下载你的论文原文。

你丢进去的它尽量吐出来的
投入Google Scholar / 主页 / LinkedIn
产出论文列表、领域标签、公开主页摘要
投入CV / 简历 PDF
产出学历、职位、工作地等可复用字段
投入你补的事实与 means
产出案卷档案、证据缺口、后续起草素材

统计评估你的申请水平

基于全网公开的 7,724 个 NIW、2,679 个 EB‑1A、179 个 O‑1 获批案例，看看你在这一万多人里大概是什么水平——论文数、引用大概落在哪个位置。

这只是已获批样本里的位置，不是获批概率——页面上也会标清楚 Approved cases only。

很多人自己办的时候，卡在不知道自己算强还是弱。这一步先把参照系摆出来。

步骤二：锁定核心方向，收集证据（Stage II）

Agent 会先给出一句 Proposed Endeavor 的草案，评分它的可执行性，你选定后锁定这句话——之后所有文书都原句引用它，不会中途改口。

方向锁定后，Agent 把还缺的展品列成证据清单，并自动抓取你论文的引用文章，筛出独立引用、逐篇核实来源，避免用无关或重复引用凑数。

步骤三：按官方框架起草整套文书（Stage III）

不是给你一段「看起来像律师写的」空话，而是照移民局的法律框架把案件骨架搭出来：申请陈述（PES）、支持信 / 推荐信初稿，还有一份 index，标清每句主张对应哪份证据。

Skill 先把这些草稿按章节写好，你负责核实事实、把证据补上。

步骤四：浏览器向导填官方表格（Stage IV）

文书定稿之后，Skill 会先把能确定的字段自动写进 answers.json，再打开浏览器向导让你逐项确认；AI 推断出来的字段会特别标出来，你改一下就清除标记。确认完，本地脚本把 I‑140、ETA‑9089 Appendix A 等官方 PDF 直接填好，能自动填的不用你再抄一遍。

步骤五：打包，按官方顺序邮寄（Stage V）

正式打包前，Skill 会先给案卷做一次红队检查：挑出没写来源的说法、缺独立证据支撑的关键论点、失效的引用、还没填完的占位符，再逐条对照十二条 RFE 预防规则；查出来的问题都要处理掉，或者你自己确认接受，不会悄悄放过。

检查通过后，材料按 USCIS 要求的顺序整理成一份可以直接打印、签字、邮寄的文件包，并按你所在的州自动匹配对应的 lockbox 邮寄地址。

这是自助工具生成的文书和查漏检查，不是律师审阅，也不是递交前的最终把关；正式递交前建议自己再核对一遍。
