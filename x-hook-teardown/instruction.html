Who it is for

Creators, ghostwriters, and growth operators who want to reverse-engineer why a post works — and leave with a template they can reuse.

Strong fit

  • Viral tweet / thread teardowns for learning
  • Hook formula identification with confidence
  • Blank templates with named slots
  • Paste-only workflows (no X login)
  • Optional URL fetch when an Apify token exists

Not the right tool

  • Auto-posting, liking, or scheduling on X
  • Guaranteeing virality or engagement
  • Full campaign packs across many channels
  • Scraping accounts at scale
  • Inventing metrics the post does not show

How it works

Input is auto-detected. Pasted text always wins over fetched text.

01 · DETECT

Read the input shape

URL-only, text-only, URL+text, or thread paste. Ask for paste only when needed.

02 · CLASSIFY

Pick the formula

Map to H1–H11, score confidence, infer the likely engagement goal.

03 · STRUCTURE

Label the beats

Hook line, body beats, closer, reaction devices, per-tweet roles for threads.

04 · PACKAGE

Validate delivery

Write source.txt, teardown.json, tearsheet.html, then run the validator.

Dependencies

Python 3 standard library for detect / validate / render. Optional APIFY_TOKEN only for URL-only auto fetch. No Publora. No X API required.

Limits

A passing report proves package structure, not that the formula is uniquely correct or that a rewritten post will perform. Metrics stay unknown unless fetched.
