Step 00 · What it does

First, be clear: it does not deliver a few loose images

One Character Studio calls its built-in image generation by default and organizes the same character’s core assets, generation prompts, identity rules, and quality records into one standard folder. The default Starter profile includes four visual assets.

01

Turnaround

Four views — front, 3/4, side, and back — to pin down the character’s structure and back-side details.

02

Expressions

Six facial expressions for social content, stickers, dialogue, and emotional range.

03

Poses

Four full-body poses that show the character in motion, in professional actions, or in signature brand gestures.

04

Hero Portrait

One high-finish hero visual suitable for covers, avatars, or promotional placements.

Current capability boundary: the older description stating that the Skill “outputs prompts only and does not generate images directly” is outdated. The current release generates images by default and requires every asset to pass a consistency review before delivery.

Step 01 · Prepare

Prepare a reference image where identity anchors are clearly visible

The reference image sets the character baseline for every asset that follows. Whenever possible, use a front or 3/4 view with the subject complete, minimal occlusion, and legible costume and colors. If the image contains multiple characters, state clearly which one should be processed.

  • The subject is clear; the face, hairstyle, or species traits are not heavily occluded
  • Primary costume colors, fixed accessories, signature props, and body proportions are identifiable
  • No watermarks, platform UI, or large blocks of unrelated text cover the character
  • You hold the rights to use or adapt this image
Do not skip the rights check. Unsourced web images may serve as internal style references, but they should never go straight into commercial deliverables. Before commercial use, also review the generation platform’s terms, portrait rights, trademarks, and character IP rights.
Step 02 · Request

Tell the agent who the character is, where it will be used, and what to deliver

You do not need to write a long professional prompt up front. Hand the reference image to the agent and add the character’s intended use, the traits that must be preserved, and the asset scope. When you have no special requirements, the full Starter set is the recommended default.

Recommended prompt · copy and paste
Please use One Character Studio to process the character reference image I provide.

Character purpose: [e.g., brand mascot / comic character / game NPC / VTuber avatar]
Must preserve: [list the most important hairstyle, ears, costume pieces, accessories, colors, or props]
Allowed to vary: [e.g., expressions, poses, camera angles, and simple backgrounds]
Asset scope: Full Starter set — four-view turnaround sheet, six expressions, four poses, and one hero portrait.

Workflow requirements:
1. Analyze the reference image first and build a character lock. If the back view or occluded areas require reasonable inference, state your assumptions explicitly before generating anything.
2. Once I confirm the character lock, generate only ONE asset per run, always carrying the same canonical reference image and the approved character lock.
3. Review every image for consistency across silhouette, facial features, costume, style, and color palette on the 8-point rubric. Any asset scoring below 7/8 or showing hard drift must be repaired in a targeted way — never regenerate assets that already passed.
4. The final delivery must include: all final images, the character lock, the complete prompt used for each asset, the consistency review record, a contact sheet, a manifest, and the validation results.

Step 03 · Character lock

First confirm what makes this character still this character

The agent organizes the stable traits found in the reference image into a character lock. Review three things carefully: fixed anchors, allowed variations, and forbidden drift. Only a clear character lock gives every later image a consistent standard to be judged against.

Fixed anchors

Silhouette, face, proportions, costume pieces, color palette, and art style. They must persist in every single image.

Allowed variations

Expressions, poses, camera angles, and simple backgrounds. They are what truly brings the character to life.

Forbidden drift

Extra ears or tails, costume changes, lost props, age changes, species changes, abrupt style shifts, or unexpected text.

Milo the Raincoat Fox · Character Lock Excerpt
Must keep:
• Two upright triangular fox ears
• One large fluffy tail with a cream-colored tip
• Mustard-yellow hooded duffle coat with exactly two dark-brown toggles on the front
• Teal crossbody bag with a single diagonal shoulder strap
• Fixed palette: orange, mustard yellow, teal, cream white, dark brown
• Vintage comic texture: bold ink lines, halftone dots, and paper grain

Allowed to vary: expressions, poses, camera, simple paper-texture backgrounds
Forbidden drift: missing or extra ears, missing or extra tails, recolored or missing coat/bag, photorealism, extra hats or weapons, any text or watermarks
Points you need to confirm: back-side structure not visible in the reference, the routing of occluded accessories, ambiguous colors, and the character’s age. If the agent’s inference would change the character design, confirm it before any generation.
Step 04 · Generate one by one

Generate the four asset types separately, always with the same reference image

Every generation run must include both the canonical reference image and the locked character lock. Never ask for “everything drawn in one call” — otherwise it becomes impossible to tell which step introduced the drift.

Turnaround

Cover the front, 3/4, side, and back views first. Keep a neutral stance, consistent scale and lighting, and no text labels.

Expressions

Then produce six head-and-shoulder expressions. Only the emotion changes — never the face shape, hairstyle, ears, skin tone, or collar.

Poses

Next, four full-body poses. Poses may vary; prop count, costume structure, and character proportions may not.

Hero Portrait

Finally, the hero portrait. Composition and background may be enhanced, but the character identity must fully obey the character lock.

For dual-subject or mount characters, write the combined relationship into the lock

In the green-haired elf case, for example, the elf and the unicorn are not two interchangeable elements but one combined identity: fixed glasses, an amethyst staff, bronze armor, and an ivory-white unicorn with a single horn. Poses may change; the number of subjects and the key props may not.

Step 05 · Review

Every image must pass the 8-point review rubric

The review is not about whether an image merely “looks good” — it judges whether the new image is still the same character. Four dimensions, each scored 0–2; a total of at least 7 with no hard failures is required for an asset to enter the final folder.

Runtime varies with character complexity, generation queue, and repair rounds; it should not be read as a fixed commitment.

Step 06 · Repair

When something fails, repair only the failed item

Do not regenerate the entire asset set just because an accessory disappeared in one expression. Keep the images that passed, describe the specific problem in the failed asset, and attach the canonical reference image and character lock again.

Targeted repair prompt · copy and paste
Please repair ONLY the expressions asset. Do not redo the turnaround, poses, or hero-portrait assets that already passed.

Current issue: in expression #4, the teal crossbody bag strap has disappeared, and the right ear is rounder than in the reference image.
Repair requirements: restore a single teal diagonal shoulder strap; keep both ears slim and triangular; leave all other facial structure, costume, colors, halftone dots, and paper texture unchanged.

Continue using the same canonical reference image and the approved character lock. The new image must not contain any text, labels, logos, or watermarks. Re-run the 8-point consistency review after regenerating, and record the new prompt together with the review notes.
  • State exactly which asset, view, or panel has the problem
  • Describe only the drift that needs fixing — do not rewrite the whole character spec
  • Require the correct traits and the already-passed assets to remain intact
  • Re-score after the repair and record the new prompt with specific review notes
Step 07 · Validate & deliver

In the end, don’t just take the images — take the complete asset pack

A complete delivery should answer three questions: who the character is, how each image was generated, and why each image was judged acceptable. That is what lets the next creator or agent keep extending the character reliably.

character-pack/ ├─ source/ │ └─ reference.png # canonical reference image ├─ final/ │ ├─ turnaround.png # four views │ ├─ expressions.png # six expressions │ ├─ poses.png # four poses │ └─ hero-portrait.png # hero portrait ├─ prompts/ │ ├─ turnaround.md │ ├─ expressions.md │ ├─ poses.md │ └─ hero-portrait.md ├─ character-lock.json # character identity rules ├─ consistency-review.json # per-asset review scores and notes ├─ manifest.json # asset and prompt index ├─ contact-sheet.svg # contact sheet └─ validation.json # structure validation results
Final pre-delivery check: all four final assets exist; each has its corresponding prompt and review record; the character lock status is locked; validation is pass; there are no errors or unexplained warnings.
Step 08 · Extend

Reuse the character lock for stickers, social content, and story scenes

Once the Starter pack is complete, there is no need to re-invent the character. Later tasks keep referencing the same canonical reference image and character lock, with the approved hero portrait or turnaround as supporting visual evidence.

Social stickers

Extend the six expressions into high-frequency communication gestures: greetings, thanks, reminders, likes, and more.

Brand content

Keep the fixed costume and palette for holiday posters, product detail page illustrations, and social media covers.

Story & storyboards

Add environments, interacting characters, and sequential actions without changing the character’s identity.

Extension prompt · copy and paste
Please continue from the completed character asset pack — do not redefine the character.

New task: create 6 social stickers for this character expressing "hello, got it, thank you, keep going, one moment, done."
You must keep using source/reference, the character lock, and the approved hero portrait as visual grounding. Expressions and gestures may change; the face, proportions, costume, fixed accessories, color palette, and art style may not. Generate and review each sticker individually, one at a time. No text inside the artwork — I will add captions later in design software.
Quick checklist

One-Page Checklist

  • The reference subject is clear and you hold legal usage rights
  • Purpose, must-keep traits, and asset scope are clearly stated
  • The character lock is confirmed, including allowed variations and forbidden drift
  • The four asset types were generated one by one, each carrying the same canonical reference
  • Each asset scored at least 7/8 with no hard failures
  • Failed assets were repaired in a targeted way, without redoing passed assets
  • Prompts, review records, contact sheet, manifest, and validation results all ship with the pack
