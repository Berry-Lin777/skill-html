One Character Studio · Instruction

One Character Studio Skill

这不是“一句话批量生图”。完整流程包含身份锁定、逐项生成、逐图审查、定向返修与结构化打包。按本教程操作，你会得到能继续使用、便于交接的角色生产资料。

Step 00 · What it does

先弄清楚：它交付的不是几张散图

One Character Studio 默认调用内置图片生成功能，并把同一个角色的核心资产、生成提示词、身份规则与质量记录整理到一个标准文件夹里。默认 Starter 版本包含四项视觉资产。

01

Turnaround

正面、3/4、侧面、背面四视图，用于明确角色结构与背部信息。

02

Expressions

六种面部表情，用于社交内容、贴纸、对白与情绪变化。

03

Poses

四组全身动作，用于展示角色动态、职业行为或品牌动作。

04

Hero Portrait

一张适合封面、头像或宣传位的高完成度主视觉。

当前能力边界：旧版说明中“只输出提示词、不直接生成图片”的描述已经过时。当前正式版本默认完成图片生成，并要求每张资产通过一致性复核后再交付。

Visual references

先知道一套角色资料，通常要解决哪些问题

不同项目会需要多视图、表情、动作、服装结构、道具或材质细节。One Character Studio 的 Starter 包先完成最通用的四类资产，再按需要继续扩展。

以上为用户提供的外部视觉参考，仅用于帮助理解角色资料的常见形态，不属于本教程的生成结果。

Step 01 · Prepare

准备一张能看清身份锚点的参考图

参考图决定了后续全部资产的角色基准。尽量使用正面或 3/4 视角、主体完整、遮挡少、服装和配色可辨的图片。多角色画面应先明确要处理哪一个角色。

  • 主体清晰，脸、发型或物种特征没有被大面积遮挡
  • 服装主色、固定配件、标志性道具和身体比例可以辨认
  • 图片没有水印、平台界面或大量无关文字覆盖角色
  • 你拥有使用或改编这张图片的权利
不要跳过授权检查。来源不明的网图可以作为内部审美参考，但不应直接进入商业交付物。商用前还需核查生成平台条款、人物肖像、商标与角色 IP 权利。
Step 02 · Request

告诉 Agent：角色是谁、用在哪里、要交付什么

你不需要先写一大段专业提示词。把参考图交给 Agent，并补充角色用途、必须保留的特征和资产范围即可。没有特殊要求时，建议直接使用 Starter 全套。

推荐提词 · 可直接复制
请使用 One Character Studio 处理我提供的角色参考图。

角色用途：[例如：品牌吉祥物 / 漫画角色 / 游戏 NPC / 虚拟主播]
必须保留：[列出最重要的发型、耳朵、服装、配件、颜色或道具]
允许变化：[例如：表情、动作、镜头角度和简单背景]
资产范围：Starter 全套——四视图转身图、六表情、四动作、主视觉。

请先分析参考图并建立角色锁；如果背面或遮挡部分需要合理补全，请先说明。确认角色锁后，每次只生成一项资产。每张图都要按轮廓、五官、服装、风格与配色进行一致性审查，低于 7/8 或出现硬性漂移时定向返修。最后交付图片、角色锁、完整提示词、审查记录、总览图、清单与验证结果。

想要更小或更大的包，也可以直接说

范围适合什么情况建议说法
Core只需要基础结构和一个主视觉“先做 Core：角色锁、转身图和主视觉。”
Starter第一次完整建立角色资产“按默认 Starter 全套制作。”
Extended已有基础包，要追加贴纸、社媒、场景或服装“沿用现有角色锁，新增 6 张社交贴纸。”
Step 03 · Character lock

先确认“这个角色为什么还是这个角色”

Agent 会把参考图里的稳定特征整理成 character-lock。你要重点检查三类内容：固定锚点、允许变化、禁止漂移。只有角色锁清楚，后面的图片才有统一判断标准。

固定锚点

轮廓、脸、比例、服装部件、配色和画风。它们必须在每张图中持续出现。

允许变化

表情、动作、镜头角度和简单背景。它们负责让角色真正“动起来”。

禁止漂移

多耳、多尾、换装、道具丢失、年龄改变、物种变化、风格突变或意外文字。

Milo 雨衣狐狸 · 角色锁节选
必须保持：
• 两只竖立的三角狐耳
• 一条奶油色尾尖的蓬松大尾巴
• 芥末黄连帽牛角扣外套，正面恰好两枚深棕色牛角扣
• 青绿色斜挎包与一条斜向肩带
• 橙、芥末黄、青绿、奶油白、深棕的固定配色
• 粗墨线、网点与纸张颗粒的复古漫画质感

允许变化：表情、动作、镜头、简单纸张质感背景
禁止漂移：缺耳或多耳、缺尾或多尾、外套/挎包改色或消失、写实化、额外帽饰武器、任何文字或水印
需要你确认的地方：参考图看不到的背面结构、被遮挡的配件走向、含糊不清的颜色与角色年龄。如果 Agent 的补全会改变角色设定，应先确认再生成。
Step 04 · Generate one by one

四类资产分开生成，始终携带同一参考图

每次生成都要同时使用规范参考图和已锁定的 character-lock。不要在一次调用里要求“把所有东西都画完”，否则很难判断是哪一步引入了漂移。

Turnaround

先解决正面、3/4、侧面、背面四个角度。保持中性站姿、相同尺度和光照，不加文字标签。

Expressions

再做六种头肩表情。只让情绪变化，不改变脸型、发型、耳朵、肤色或服装领口。

Poses

接着做四组全身动作。动作可以变化，道具数量、服装结构和角色比例不能变化。

Hero Portrait

最后制作主视觉。可以加强构图与背景，但角色身份仍需完全服从角色锁。

双主体或坐骑角色，要把组合关系写进锁里

例如绿发精灵案例中，精灵与独角兽不是可随意替换的两个元素，而是一个组合身份：固定眼镜、紫晶法杖、青铜护甲，以及象牙白、单角的独角兽。动作可以变化，主体数量和关键道具不能变化。

Step 05 · Review

每张图都要过 8 分审核表

审核不以“好不好看”作为唯一标准，而是判断新图是否仍然是同一个角色。四个维度各 0–2 分，合计至少 7 分，并且没有硬性失败，才能进入 final 文件夹。

0–2轮廓与比例
0–2五官与身份
0–2服装与配件
0–2风格与配色
检查项2 分1 分0 分 / 硬性失败
轮廓与比例耳、尾、体型与原图稳定轻微比例波动多耳、多尾、物种或年龄改变
五官与身份脸型、眼睛、发型和标记一致小范围形状变化像另一个角色、关键标记消失
服装与配件结构、数量与穿戴关系一致非关键小细节波动换装、关键道具丢失或数量错误
风格与配色媒介、线条、纹理与色板一致饱和度或质感略有差异写实/卡通跨风格突变，或意外文字水印

运行时长会受角色复杂度、生成队列和返修次数影响，不应视为固定承诺。

Step 06 · Repair

不合格时，只修出错的那一项

不要因为一张表情图的配件消失，就重新生成全部资产。保留已通过的图片，针对失败资产说明具体问题，并再次携带规范参考图与角色锁。

定向返修提词 · 可直接复制
请只返修 expressions 资产，不要重做已经通过的 turnaround、poses 和 hero-portrait。

当前问题：第 4 个表情里的青绿色挎包肩带消失，且右耳形状比参考图更圆。
修复要求：恢复一条青绿色斜向肩带；两只耳朵保持细长三角形；其他面部结构、服装、配色、网点与纸张质感保持不变。

继续使用同一张规范参考图和已批准的 character-lock。新图中不要出现文字、标签、标志或水印。生成后重新进行 8 分一致性审查。
  • 明确指出哪一个资产、哪一个视图或面板有问题
  • 只描述需要修复的漂移，不重写整套角色设定
  • 要求保留已正确的特征与已经通过的其他资产
  • 返修后重新打分，并记录新的提示词与具体审查说明
Step 07 · Validate & deliver

最后不要只拿走图片，要拿走完整资产包

完整交付应能回答三个问题：角色是谁、每张图怎么生成、为什么这张图被判定为合格。这样下一位创作者或 Agent 才能继续稳定扩展。

character-pack/ ├─ source/ │ └─ reference.png # 规范参考图 ├─ final/ │ ├─ turnaround.png # 四视图 │ ├─ expressions.png # 六表情 │ ├─ poses.png # 四动作 │ └─ hero-portrait.png # 主视觉 ├─ prompts/ │ ├─ turnaround.md │ ├─ expressions.md │ ├─ poses.md │ └─ hero-portrait.md ├─ character-lock.json # 角色身份规则 ├─ consistency-review.json # 逐项审查分数与说明 ├─ manifest.json # 资产与提示词索引 ├─ contact-sheet.svg # 总览图 └─ validation.json # 结构验证结果
交付前最后确认：四张最终资产都存在；每张都有对应提示词与审查记录；角色锁状态为 locked；验证结果为 pass；没有错误或未解释的警告。
Step 08 · Extend

沿用角色锁，继续做贴纸、社媒和故事场景

Starter 包完成后，不需要重新“发明”角色。后续任务继续引用同一规范参考图与 character-lock，并把已通过的主视觉或转身图作为辅助视觉依据。

社交贴纸

在六表情基础上扩展问候、感谢、催更、点赞等高频沟通动作。

品牌内容

沿用固定服装与配色，制作节日海报、详情页插图、社交媒体封面。

故事与分镜

在不改变角色身份的前提下，增加环境、互动角色与连续动作。

继续扩展提词 · 可直接复制
请沿用已完成的角色资产包，不要重新定义角色。

新任务：为该角色制作 6 张社交贴纸，分别表达“你好、收到、谢谢、加油、稍等、完成”。
必须继续使用 source/reference、character-lock，以及已通过的 hero-portrait 作为视觉依据。允许改变表情和手势，不允许改变脸、比例、服装、固定配件、色板与画风。每张贴纸单独生成、单独审查；画面不要出现文字，我会在设计软件中后期添加。
Quick checklist

一页检查清单

  • 参考图主体清晰，并且拥有合法使用权
  • 用途、必须保留特征和资产范围已经说明
  • character-lock 已确认，含允许变化与禁止漂移
  • 四类资产逐项生成，每次都携带同一规范参考图
  • 每项得分至少 7/8，且没有硬性失败
  • 失败资产已定向返修，没有重做已通过资产
  • 提示词、审查记录、总览、清单和验证结果全部随包交付
