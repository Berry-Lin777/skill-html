ZIWEI CHART · USER GUIDE

使用教程

提供三项出生信息，在你的 Agent 里开始规则排盘。

运行环境：Claude Code
Skill：ziwei-chart
必填信息：日期、时辰、性别
演示：2005-03-15 · 07:00（7am）· 男
本 Skill 的输出属于传统文化与娱乐参考，不具备科学预测能力，也不能替代投资、医疗、法律、婚恋等专业建议。
01
STEP 01

先确认三项出生信息

操作步骤

准备以下三项必填信息：
  • 公历出生日期
  • 出生时辰或具体小时
  • 性别
本 Skill 的排盘只使用日期、时辰和性别。
时辰比地点重要。若只知道“大约早上”，最好先确认是否跨越两个时辰；输入时间不同，命盘可能随之变化。
02
STEP 02

用一句自然语言发起排盘

操作步骤

直接写出生年月日、时间和性别即可。日期建议写完整年份，时间尽量使用 24 小时制。
Agent 会加载 ziwei-chart、整理参数，并按照 Skill 的固定规则进行计算。
发给 Claude Code
帮我排一个2005年3月15日07:00（7am）出生的男命。
03
STEP 03

查看完整命盘

操作步骤

查看排盘结果中的公历、农历、干支、五行局、命主、身主、身宫，以及十二宫的地支、主星、吉星与煞星。
结果采用结构化表格展示，便于复制、查找和后续提问。
04
STEP 04

继续查看四化、大限和盘面摘要

操作步骤

继续查看四化、大限和盘面要点。四化会列出化禄、化权、化科、化忌对应的星曜与宫位；大限按年龄区间展示。
命盘生成后，可以围绕同一份结构化结果继续向当前 Agent 提问。
继续提问
请只基于刚才生成的命盘，用通俗语言解释命宫、财帛宫和官禄宫分别代表什么。请区分传统术语和事实，不要把内容写成确定性的预测。
!
TROUBLESHOOTING

Windows 出现乱码或读取失败怎么办

如果 Windows 控制台与结果文件的编码不一致，可能出现乱码或 UnicodeDecodeError。这不代表排盘失败；请先让 Agent 使用 UTF-8 重新读取结果。

可以直接发送
刚才输出出现乱码。请确认结果文件使用 UTF-8 编码，并以 UTF-8 重新读取后展示完整命盘；不要因为控制台乱码而重新计算出生参数。
演示环境：Claude Code · Windows · ziwei-chart 0.1.0。传统文化娱乐工具，不提供科学预测或专业决策建议。
