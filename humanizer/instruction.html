Good fit

Use it where voice matters.

Humanizer is strongest when the facts already exist and the problem is expression. It should not be used to invent evidence or conceal authorship where disclosure is required.

Works well for

  • Articles, product updates, and knowledge-base copy
  • Drafts with repetitive rhythm or inflated language
  • Text that needs a clearer personal or brand voice
  • Local documents when the user explicitly requests edits

Do not use it for

  • Evading academic, workplace, legal, or publishing disclosure rules
  • Adding facts, quotes, or sources that are not in the input
  • Replacing expert review of legal, medical, or regulated copy
  • Claiming that rewritten text is guaranteed to appear human-authored
Technical truth

Lightweight by design.

The package contains editorial instructions and examples. It has no bundled executable, model, scoring service, or network integration. Actual rewriting is performed by the host agent using the loaded rules.

Permissions

Read, Write, Edit, Grep, Glob, and AskUserQuestion are declared. Scope file access to user-selected content.

Dependencies

No API key, package installation, or remote service is required for the instruction workflow.

Delivery

Plain text or Markdown, with an optional concise explanation of what changed.
