The workflow

From brief to portable interface.

The skill supplies a configured project foundation and a repeatable packaging path. You remain in control of the application’s content, interaction model, and visual decisions.

1

Frame the artifact

Define the audience, key tasks, required views, interactions, data shape, and any visual constraints.

2

Scaffold the project

The initializer creates a React + TypeScript Vite project with Tailwind, aliases, themes, and a broad shadcn/ui component set.

3

Build the experience

Compose real views and stateful interactions in the generated source, using the included component library where it helps.

4

Bundle and hand off

Parcel builds the project and html-inline folds the output into a single bundle.html for direct sharing.

How to ask

Give it a product brief, not a color request.

Better input describes what people need to accomplish. Include a visual direction only when it supports the subject and audience.

A useful brief includes

  • Primary user and the decision or task they must complete
  • Required screens, sections, controls, and state transitions
  • Sample data or a clear data schema
  • Target environment and delivery expectations
  • Accessibility, responsive, or brand constraints

Choose it when

Complexity should earn its place.

This is a substantial frontend toolchain. It is most useful when a simple document or a few lines of HTML would not express the experience.

✓ A strong fit

  • Multi-view or multi-component interfaces
  • Artifacts with filters, selection, forms, or local state
  • Experiences that benefit from shadcn/ui primitives
  • Projects that need editable source plus one-file delivery

× Use something lighter

  • A static memo, poster, or uncomplicated landing page
  • A server-backed application that must keep secrets
  • A build that must complete without package-registry access
  • A tiny snippet where a full React toolchain adds no value

Before you begin

Local tools, networked setup.

No API key is required by the skill itself. The initialization and bundling steps do install JavaScript packages, so the environment matters.

18+ Node.js

Node 18 or newer is required. The initializer selects a compatible Vite version.

pnpm Package manager

The script attempts a global pnpm install through npm when pnpm is unavailable.

↗ npm registry access

Initialization and packaging fetch dependencies. The first installation is comparatively heavy.

index Root HTML entry

The bundling script requires an index.html file at the project root.

Delivery boundary

A self-contained browser file cannot safely hide credentials or replace a backend. Do not embed secrets in client-side source. Remote APIs, hosted media, or browser-restricted resources can also make your final experience network-dependent even when the local build assets are inlined.

Build the interface at full strength. Hand it over as one tidy artifact.
