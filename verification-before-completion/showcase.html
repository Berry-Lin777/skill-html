The gate

A claim cannot skip the middle.

The skill inserts five required decisions between confidence and a completion statement. Every stage narrows the wording to observable facts.

01 · Identify

Split the claim

Separate contract coverage, package validation, and live behavioral compliance.

02 · Select

Match proof

Choose a command that directly tests each individual assertion.

03 · Run

Make it fresh

Execute now. Historical output and confidence do not count.

04 · Read

Keep the failure

Review full output, exit status, missing dependencies, and untested areas.

05 · State

Say only this

Publish the narrowest conclusion supported by the collected evidence.
