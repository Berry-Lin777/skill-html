01 / Representative input

The source exposes behavior, not a prewritten diagram.

The fixture contains deterministic toy-DH key pairs, a pre-shared authentication key, HMAC checks, session-key derivation, and three explicit rejection points. It is a safe, reproducible test artifact—not production cryptography.

toy_authenticated_dh.py / excerpt 
def client_start():
    client_private, epk_c = generate_ephemeral_keypair(17)
    mac_c = HMAC(AUTH_KEY, epk_c || nonce_c)
    return ClientHello(epk_c, nonce_c, mac_c)

def server_process_client_hello(hello):
    if not compare_digest(hello.client_mac, expected):
        raise HandshakeAbort("BAD_CLIENT_MAC")
    shared = DH(server_private, hello.client_ephemeral_pub)
    session_key = HKDF_like(shared, transcript)
    return ServerHello(epk_s, nonce_s, mac_s)

def client_process_server_hello(...):
    if not compare_digest(server_mac, expected):
        raise HandshakeAbort("BAD_SERVER_MAC")
    return session_key, ClientFinished(finished)

# Server verifies finished, then returns SessionAccepted.

Participants

Client and Server, inferred from orchestration functions and message types.

Cryptographic work

Authentication

Mutual pre-shared-key authentication followed by session-key confirmation.

Security caveat

Fixed private values mean the fixture does not provide real forward secrecy.
