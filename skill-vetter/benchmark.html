Optional network path

The lookup works, with boundaries.

The GitHub examples need curl, jq, and public network access. They require no API key, but anonymous rate limits, local proxy settings, and moving branch content can affect repeatability.

Observed transport check

A read-only request to a public GitHub repository returned structured metrics and was parsed by jq. This verifies the optional command path in this environment, not the safety of that repository.

Known limits

Where human review still decides.

The Skill’s simplicity is useful, but its strongest language must not be confused with detection accuracy.

Popularity is not proofStars and known authors are context signals, not evidence that a package is safe.
Simple patterns can over-reportBase64, shell access, or secret use may be legitimate when justified and scoped.
Fetched content is untrustedA reviewer must treat target instructions as data and avoid following embedded commands.
Future updates are out of scopeA clean review covers only the exact files inspected at that time.
