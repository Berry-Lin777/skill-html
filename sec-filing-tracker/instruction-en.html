SEC Filing Tracker

English User Guide | Search public SEC EDGAR filings in natural language

What it does Search a keyword, person, event, or product name across EDGAR filings. Results provide the company, form type, filing date, accession number, and a link to the original SEC filing.

1. Before you begin: confirm the Skill is available

Once installed, the system recognizes sec-filing-tracker. No API key is required; the Skill uses the public SEC EDGAR Full-Text Search service.

Figure 1 | The Skill is installed and ready to use.

Important A search match only means that a term appears in a filing. It is not an investment recommendation or a conclusion about the company. Always review the original filing.

2. Ask a clear question in one sentence

A useful query combines a keyword or exact phrase with optional form types, a date range, and a result limit. Example: Search all SEC filings containing “OpenAI” and return the 20 most relevant filings.

Figure 2 | Start with a natural-language request.

The Skill converts the request into search parameters and returns results in EDGAR relevance order. It deduplicates results by accession number, so multiple matching documents in the same filing do not create duplicate rows.

Figure 3 | Returned records show the company, form, filing date, and accession number.

3. Common search patterns

1. Exact phrase + 10-K + date range

Put a phrase in quotation marks and specify both a form type and a time period. Example: Find 10-K filings submitted in 2025 that contain the exact phrase “material weakness.”

Figure 4 | Exact-phrase search with a 10-K and 2025 filter.

2. 8-K event tracking + date range

8-K filings commonly disclose material current events. Search for terms such as acquisition, management change, or cybersecurity incident and restrict the date range when needed.

Figure 5a | Request: 8-K filings mentioning acquisition between January and June 2025.

Figure 5b | Structured 8-K results for the acquisition search.

How to read “gte” If total_matches is marked gte 10000, EDGAR counted at least 10,000 matches. The actual number may be higher; it is not an exact total.

3. Multiple forms and a form-type count

Search 10-K and 10-Q filings together, then use the form breakdown to compare the returned filings by form type. EDGAR may include amendments such as 10-Q/A.

Figure 6 | Search for “artificial intelligence” and count results by form type.

4. Name tracking

You can also search for people or organizations. For example, search “Sam Altman” to see the companies and filing types involved. Use quotation marks to reduce noise.

Figure 7 | Name tracking returns companies, form types, and filing dates.

5. Zero results are not an error

When an exact phrase does not appear in EDGAR, the Skill returns zero results while confirming that the data source is healthy. This is a valid “no match” outcome, not a failed search.

Figure 8 | A clean zero-result response with a healthy source status.

6. What to do with the results

  • Review the company, form type, and filing date to remove irrelevant records.

  • Open the original SEC filing link and read the matching term in context.

  • Reuse the same keyword, form, and date rules for periodic tracking.

  • Base any interpretation on the original filing and its full context, not on a keyword match alone.

7. Ready-to-use query templates

Search all SEC filings containing “[keyword]” and return the [number] most relevant filings.

Find [form type] filings submitted in [year] that contain the exact phrase “[phrase].” Return no more than [number] results.

Find [form type] filings submitted between [start date] and [end date] that mention “[event].”

Search all SEC filings mentioning “[person or organization]” and list the companies and form types involved.

Final reminder SEC Filing Tracker is designed for discovery and verification of public filings. It does not provide investment advice.
