中文版使用教程｜用自然语言检索美国 SEC EDGAR 公开披露文件

美国证券交易委员会（SEC）总部。图片：Ajay Suresh，Wikimedia Commons，CC BY 4.0；本教程不代表 SEC 对本 Skill 的认可或背书。

它能做什么 输入一个关键词、人物、事件或产品名称，并按文件类型、日期范围和返回条数筛选；结果会给出公司、表单、日期、备案号及可继续核验的 SEC 原始文件链接。

一、开始前：确认 Skill 已安装

安装完成后，系统会识别 sec-filing-tracker。你不需要填写 API Key；该工具会通过 SEC 的公开 EDGAR 全文检索服务获取公开文件。

图 1｜系统已识别 Skill，并说明了它支持的中文提问方式。

使用边界 搜索命中仅表示关键词出现在 SEC 文件中，并不代表公司与该关键词存在确定关系，也不构成投资建议。请始终打开原始链接阅读上下文。

二、如何提问：一句话说明你的筛选条件

最实用的提问结构是：关键词／精确短语 + 文件类型 + 时间范围 + 最多返回多少份。例如：搜索所有包含“OpenAI”的 SEC 文件，返回相关性最高的 20 份。

图 2｜基础关键词搜索：直接用自然语言说明查询目标。

工具会将问题转换为检索条件。结果按 EDGAR 相关性排序，并按备案号去重：同一份备案内即使多个附件命中，也只会保留一条记录。

图 3｜返回结果包含公司、表单、日期和备案号，可作为后续核验入口。

三、常用检索方式

1. 精确短语 + 10-K + 日期筛选

把短语放在引号中，并明确表单类型和日期范围。例如查找 2025 年提交、包含精确短语 “material weakness” 的 10-K 文件，最多返回 10 份。

图 4｜精确短语、10-K 和全年日期范围组合筛选。

2. 8-K 事件追踪 + 日期范围

8-K 常用于披露重大临时事项。你可以围绕 acquisition、management change、cybersecurity 等事件词，限定某一段时间。

图 5｜在 2025 年上半年检索提到 acquisition 的 8-K 文件。

读懂计数 当 total_matches 显示 gte 10000，表示 EDGAR 的匹配数量至少为 10,000，真实数量可能更多；它不是精确总数。

3. 多表单搜索与类型统计

可同时检索 10-K 和 10-Q，再查看每种文件类型的数量。结果中可能包含修订版，如 10-Q/A；这是 EDGAR 的真实表单类型。

图 6｜搜索 “artificial intelligence”，并按 10-K、10-Q 类型统计。

4. 人物或机构名称追踪

除了主题词，也可以搜索姓名。例如搜索 “Sam Altman”，即可查看涉及的公司和文件类型。建议将名称放入引号中，避免拆分匹配带来的噪声。

图 7｜人物名称追踪：返回涉及的公司、文件类型与备案日期。

四、没有结果也不是报错

若一个精确短语没有出现在 EDGAR 数据库中，工具会正常返回 0 条结果，并说明数据源仍然可用。这表示“没有匹配项”，而不是搜索失败。

图 8｜零结果处理：清晰显示 0 条命中与数据源正常状态。

五、结果怎么用

  • 先看公司、表单类型和日期，快速筛掉与研究问题不相关的记录。

  • 打开 SEC 原始文件链接，确认关键词出现的位置及其上下文。

  • 需要持续跟踪时，将同一套关键词、表单和日期规则保存为固定查询，定期重新检索。

  • 如需统计、摘要或结论，请基于原始文件再进行分析；不要仅根据关键词命中下判断。

六、快速提问模板

搜索所有包含“[关键词]”的 SEC 文件，返回相关性最高的 [数量] 份。

查找 [年份] 年提交、包含精确短语“[短语]”的 [表单类型] 文件，最多返回 [数量] 份。

查找 [开始日期] 至 [结束日期] 期间，提到“[事件]”的 [表单类型] 文件。

搜索所有提到“[姓名/机构]”的 SEC 文件，并列出涉及的公司和文件类型。

最终提醒 SEC Filing Tracker 用于公开披露文件的发现与核验，不提供投资建议。任何研究判断都应回到原始 SEC 文件，并结合完整上下文。
