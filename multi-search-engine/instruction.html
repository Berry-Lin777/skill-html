The routing loop

Six decisions from query to report

Classify

Identify language, intent, freshness, geography, and whether the query is safe to disclose.

Select

Choose only the providers relevant to the task rather than sending every query everywhere.

Encode

Apply URL-safe encoding plus operators such as site:, filetype:, exact match, exclusion, or a time filter.

Fetch

Request providers sequentially in small batches with a one-to-two-second delay.

Handle blocks

Record CAPTCHA, 403, 429, reset, or timeout outcomes. Retry at most once when the host supports isolated session cookies.

Report

Merge accessible results, name each source, disclose gaps, and avoid presenting blocked providers as successful.
