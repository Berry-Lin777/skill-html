Blocking finding

The package states “all operations run locally, no external data transmission”. The core workflow necessarily sends every selected query to an external search provider. That statement must not be used as a customer promise.

REVIEW

No composite score assigned

The registry and instruction artifact are structurally usable, but real provider access is environment-dependent and the privacy claim is materially inaccurate. Treat this release as a routing guide for public queries, not a guaranteed multi-engine crawler.

Probe results are a time-and-environment-specific snapshot. Search providers can change access controls without notice. A blocked probe does not prove permanent unavailability; a successful probe does not guarantee future access.
