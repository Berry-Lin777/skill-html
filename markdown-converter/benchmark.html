Acceptance gates

The checks measure the output, not merely a zero exit code.

Structure gate

Expected Markdown shape

HTML passes only when the heading, paragraph, and list survive. CSV passes only when headers and both rows appear in a Markdown table.

Isolation gate

No unrequested network path

The fixture run passes only if cached local conversion completes with network disabled and no Azure, URL, or plugin mode enabled.

Dependency gate

Format must be installed

A format is ready only after its actual fixture converts with the declared extra. Documentation alone does not count as support.

Interpretation

What the run proves—and what it does not.

Verified local value

For simple HTML and CSV, the cached base package produced compact, readable Markdown without a remote API.

PDF claim is conditional

The skill’s basic PDF example fails in the tested base environment. Install and verify markitdown[pdf] or markitdown[all] first.

Broad support remains unverified

Word, PowerPoint, Excel, media, ZIP, EPUB, URL, Azure, and plugin-assisted paths were not exercised in this benchmark.

Recomputable conclusion

5 passed, 1 failed, 3 not run.

Five of six executable checks passed: CLI availability, HTML conversion, CSV conversion, cached offline execution, and empty plugin inventory. The PDF base-package check failed because its extra was absent. Three network-dependent paths were deliberately not run. Therefore this benchmark verifies local HTML and CSV conversion only; it does not justify an unconditional “all listed formats work” claim.
