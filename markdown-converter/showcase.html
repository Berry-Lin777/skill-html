Cached offline conversion

On July 29, 2026, uvx 0.7.13 ran cached markitdown 0.1.6 against the two local fixtures shown above. The HTML command produced fixture-html.md; the CSV command produced fixture-csv.md. Both artifact bodies were opened and compared with their source structure. The plugin inventory reported no third-party plugins. Boundary

The same base-package run did not convert PDF because the PDF optional dependency was absent. PDF and other advertised formats require their matching extras and separate verification; this showcase proves HTML and CSV only.
