What it does

One plain-text surface for many source shapes.

Preserve useful structure

Headings, paragraphs, lists, and tabular data become Markdown that remains readable by people and straightforward for downstream agents to parse.

Work locally by default

Local file conversion can remain on the machine. HTML and CSV fixtures completed without an API, upload, or network call once the package was cached.

Choose format support

Install only the extras your source type needs, or use the all-extra bundle when broad document coverage matters more than a minimal environment.

Recommended workflow

Resolve the runtime deliberately, then convert and inspect.

01 / IDENTIFY

Inspect the input

Confirm the file type, sensitivity, size, and whether its content can leave the machine.

02 / RESOLVE

Pin MarkItDown

Use a known version and add the matching extra for PDF, Office, audio, or other optional converters.

03 / CONVERT

Run locally

Write Markdown to a named output file. Avoid URL mode, Azure, and plugins unless the request explicitly requires them.

04 / REVIEW

Check structure

Inspect headings, lists, tables, links, reading order, and any extraction gaps.

05 / DELIVER

Return artifacts

Provide the Markdown file, source-to-output notes, and any format-specific limitation.

Convert quarterly-notes.html and actions.csv to Markdown locally. Preserve the heading, bullets, and table structure; do not use a remote endpoint, URL input, or third-party plugin. Return both .md files and flag any lost structure.

Pinned local examples 
uvx --from 'markitdown==0.1.6' \
  markitdown quarterly-notes.html \
  -o quarterly-notes.md

uvx --from 'markitdown==0.1.6' \
  markitdown actions.csv \
  -o actions.md

# PDF requires the optional extra:
uvx --from 'markitdown[pdf]==0.1.6' \
  markitdown report.pdf -o report.md

Safety & dependency boundary

Three switches materially change the trust model.

First run

Package resolution uses the network

uvx can run from cache, but a fresh machine must download MarkItDown and selected extras. Pin the version for repeatability.

Remote input

URL and Azure modes leave local-only territory

URL input performs network retrieval and can expose internal targets. Azure Document Intelligence uploads file bytes to the configured endpoint and needs credentials.

Plugins

Third-party code executes in process

--use-plugins loads installed Python entry points. Enable only reviewed plugins from a trusted environment.
