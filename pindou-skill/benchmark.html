Claim → gate

What the skill promises, and how it is supposed to prove it.

Passing here means the rule exists in SKILL.md / source and the official teasers show the matching artifact. It does not mean this workspace re-ran the image API.

1

Photo or text both finish the same way

edit.py vs generate.py is a documented branch. Both must write a gridded pixel image before extraction.

2

Human stop on ai_pixel.png

Step 4 is a hard STOP. N=1 asks for approval. N>1 asks which candidate to keep. Silent continue is a fail.

3

Grid mismatch is a choice, not a retry

If extract prints 44×44 against a 36×36 spec, the agent offers accept / redraw / rewrite-spec. Vague answers accept the drawn grid.

4

Snap happens in Lab, after extraction

extract_svg.py writes median RGB only. svg_to_grid.py does CIEDE2000 snap, max_colors, and must-include. RGB k-means is forbidden.

5

Background is not a bead

solid / remove backgrounds stay empty and stay out of bom.csv. Connected-component logic separates true background from holes inside the subject.

6

PNG render needs cairosvg

pattern.svg and bom.csv still write without it. pattern.png is skipped with a printed warning if cairosvg is missing.

Release gates

How a run is allowed to call itself done.

G1 · Spec in plain language

Style, size, background, max colors, keep-features, and candidate count are written to spec.json before any image call.

G2 · Correct image branch

Photo uses edit.py. Text uses generate.py. Output is a visible-grid pixel image.

G3 · Pixel STOP

User picks or rejects ai_pixel.png. No extract until that file exists.

G4 · Grid STOP

Printed extract size is compared to spec. Mismatch is a human choice.

G5 · Lab snap

CIEDE2000 mapping, max_colors, and background masks happen after raw SVG extraction.

G6 · Fresh local run

Still open for this HTML package. The official teasers are the current evidence trail.
