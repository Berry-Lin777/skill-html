STEP 02

Prepare the source image

Select the artwork you want to produce and decide how the finished item will be used. A clear image with a distinct subject usually produces the strongest result.

📷

Choose a clean source

Use a well-lit photo or illustration with clear edges and a recognizable subject.

🪄

Define the composition

Choose a full-body view, close-up, or product crop, and decide whether to remove the background.

📐

Plan the finished size

Small grids work for charms and magnets. Larger grids preserve detail for portraits, display pieces, and premium orders.

Production tip: faces, pet fur, and detailed architecture benefit from larger grid dimensions. Increase the size when product cost and assembly time allow.

Your production instruction

Use Pindou Skill to convert my attached image into a final, print-ready bead pattern.

Composition: Keep the full subject centered and fill the canvas
Background: Remove it; leave background cells blank and exclude them from the bead count
Grid size: 72 × 72
Color limit: Maximum 32 colors
Palette: Match colors against MARD 221

Complete the following workflow:
- Extract the grid colors from the image
- Match each occupied cell to the closest bead color code
- Label every occupied cell with its color code
- Add a complete color key on the right
- Show the name and required quantity of every color
- Export a print-ready PNG named “bead-pattern.png”

First create a clean pixel-grid proof and pause for my approval. After I approve it, produce the final labeled PNG pattern.

BEFORE YOU SEND

Final input checklist

These four inputs help Pindou Skill deliver a more accurate and production-friendly result.

Source image attached

The image is clear and the subject edges are visible.

✓

Grid dimensions provided

State width × height, such as 72 × 72.

✓

Color limit selected

Fewer colors simplify kitting; more colors preserve detail.

✓

Palette confirmed

Choose MARD 221 or supply your preferred brand palette.
