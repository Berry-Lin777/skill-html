Twitter Autopilot User Guide

Use Natural Language to Read Search Analyze and Manage X Content

  • Search
  • Analyze
  • Publish
  • Engage

Twitter Autopilot reads public X profiles and timelines, searches topics and accounts, analyzes replies and quote posts, and, after OAuth authorization, publishes posts, likes posts, and follows accounts. This guide uses real English-language examples to explain installation, configuration, prompt design, result interpretation, and write actions.

Usage principle  State the target, time range, result count, and output format clearly. For publishing, liking, following, or reversing an action, identify the exact target and rely on the API’s explicit success response.

1

Installation and Initial Setup

A complete installation includes SKILL.md, scripts, and references. The usual Codex installation path is ~/.codex/skills/twitter-autopilot. After installation, start a new conversation or restart the application so the skill can be loaded again.

1 Install and Verify the Skill

Send the following prompt to the AI. It will read the repository instructions, select the correct installation directory for the current tool, and check the required runtime dependencies.

Install this skill for me: https://github.com/FinchipAIOrg/twitter-autopilot. Read the repository instructions first, choose the correct installation location for my current AI tool, and install SKILL.md, scripts, and references completely. Check whether Python 3, curl, and a POSIX shell are available. When finished, tell me the installation path and whether I need to restart the application or start a new conversation to load it.

2 Configure AISA API KEY

Reading public data requires AISA_API_KEY. Obtain the key from AIsa and store it in a secure local location. Never send the key in chat or ask the AI to display its contents.

The key has been saved locally. Read it from the local file and inject it as AISA_API_KEY. Query the public profile of @elonmusk to verify that the API works. Do not display the key.

3 Authorize an X Account

Reading public content usually does not require signing in to X. Publishing posts, liking or unliking posts, and following or unfollowing accounts require OAuth authorization. Ask the AI to generate an authorization link, complete sign-in and approval in the browser, then return to the same conversation. Never provide an X password or login cookie to the AI.

If AIsa offers a pay-as-you-go plan, you may select it. Confirm the balance, fees, and expiration terms shown on the AIsa page at the time of purchase.

2

How to Write an Effective Prompt

A clear request usually contains five types of information. The AI may still complete a query when one is missing, but the result scope and presentation are more likely to differ from your intent.

  • Action: retrieve, search, compare, analyze, publish, like, or follow.
  • Target: an account, keyword, post URL, list, or community.
  • Scope: how many recent posts, how many days, popular or latest results, and whether to retrieve replies and quotes.
  • Output: an English summary, table, links, publication times, engagement metrics, or sentiment categories.
  • Boundaries: state the sample size, actual coverage, unavailable content, and the distinction between facts and interpretation.

Example prompt

Use twitter-autopilot to retrieve the latest 20 posts from @[account]. Summarize the main topics in English. List each publication time, original URL, and all engagement metrics returned by the API.

3

Review an Account’s Recent Activity

Use this workflow to track founders, official brand accounts, or industry leaders. Distinguish original posts, replies, reposts, and quote posts because engagement figures on a repost usually belong to the reposted source post.

Recommended prompt

Use twitter-autopilot to retrieve the latest 20 posts from @elonmusk. Summarize the main topics in English. For every returned post, list its publication time, post type, original URL, and all engagement metrics returned by the API. Clearly distinguish original posts, replies, reposts, and quote posts. State the actual time range covered by the results.

Check the actual time range first, then review how many original posts, replies, reposts, and quote posts appear in the sample. Publication time is based on each returned activity item; engagement figures for reposts may match the source post.

4

Search a Topic and Summarize Popular Discussion

Topic search helps identify what has attracted attention in a field. When popular results are requested, the AI prioritizes high-engagement samples. This does not cover every relevant post.

Merging duplicate content prevents multiple retellings of one announcement from occupying several positions. Claims about research breakthroughs, hiring figures, or news headlines should be identified as statements made in posts and verified against primary sources.

5

Analyze Brand Sentiment and User Needs

Brand monitoring can organize product advantages, defect reports, after-sales issues, and user requests. Classify sentiment from the post text and preserve mixed evaluations that contain both positive and negative information.

Positive, negative, and neutral labels describe the retrieved sample and do not represent all users. Report the search terms, deduplication method, actual API coverage, and number of records included in the analysis.

6

Compare Competitor Activity

When comparing brands, use consistent accounts, time windows, and focus areas, and require a source for every finding. Present official announcements as facts and label marketing lessons or strategy suggestions as interpretation.

Posting frequency may vary widely across accounts in the same period. If an announcement type is absent from the retrieved official sample, state only that it was not observed in this search. Do not infer that the brand conducted no related activity.

7

Discover Relevant Creators

Account discovery is useful for building a candidate list. Reviewing both public bios and recent posts filters out accounts that mention a keyword in the bio but do not publish related content consistently.

When only a research list is needed, explicitly say not to follow or contact anyone. This separates discovery from external interaction and avoids changing account state before candidates have been evaluated.

8

Read a Single Post in Full Context

After providing a post URL, you can retrieve the original text, conversation context, replies, and quote posts. This is useful for explaining what triggered a dispute, the main viewpoints on each side, and content unavailable because of API or account restrictions.

Recommended prompt

Use twitter-autopilot to read this post: [post URL]. Retrieve the available conversation context, replies, and quote posts. Explain in English what the original post says, what triggered the discussion, and the main supporting and opposing viewpoints. Include links to the original post and key responses. Report the engagement metrics returned by the API, the number of replies, thread records, and quote posts retrieved, whether additional pages were available, and any content that could not be obtained. Do not treat the retrieved replies and quotes as a complete or representative sample of all reactions.

The reply or quote count displayed on the original post may exceed the records returned by the API. Deleted, private, restricted, or unavailable paginated content may be missing, so conclusions should describe the main viewpoints in the visible sample.

9

Publish Posts and Perform Account Actions

Write actions change the state of the authorized X account, so the content or target must be explicit. If OAuth is active, the action can run directly. If authorization has expired, the AI will return a new authorization link.

1 Publish a Text Post

Use twitter-autopilot to publish the following text exactly as a standalone X post: [post content]. Return the actual post URL if successful; otherwise explain why it failed.

2 Publish an Image or Video

Attach the media file and state the caption explicitly in the prompt. When only one image is provided, do not ask for duplicates. If no caption is needed, explicitly request a media post without text.

Use twitter-autopilot to publish the attached image to X with this caption: [caption]. Return the actual post URL if successful; otherwise explain why it failed.

3 Follow an Account and Like a Post

Use twitter-autopilot to follow @elonmusk and like their latest post.

After retrieving several posts, you can say “like item 2” or “unlike item 5.” If multiple accounts have similar names, confirm the exact account first.

10

Interpret Results and Resolve Common Issues

Twitter Autopilot returns public data accessible at query time. Engagement figures continue to change, popular results depend on ranking, and a retrieved sample does not replace comprehensive monitoring or statistical sampling.

  • Use original links as verification entry points. A summary cannot replace the source post and full context.
  • Request the actual coverage, number of API records, deduplicated count, and classification criteria.
  • Describe official-account posts as official statements. Product performance, incidents, research findings, and customer complaints still require independent verification.
  • Reply samples may contain duplicates, giveaway templates, bot content, and multiple comments from the same user.
  • Treat publishing, liking, or following as complete only after the API explicitly returns success.
Common situation Recommended action
AISA_API_KEY is missing Store the key in a secure local file or environment variable, then ask the AI to read it locally. Never paste the key into the chat.
Authorization is required Ask the AI to generate an OAuth authorization link. Sign in and approve access in the browser, then return to the same conversation.
Search returned few results Expand the time window, add English keywords or account names, and request the actual time coverage and sample size.
Replies or quotes are incomplete Request pagination details and a list of unavailable content. Private, deleted, region-restricted, or API-limited records may be missing.
A write action failed Rely on the API response. Request the error reason, and do not treat an authorization link or submitted request as a successful action.

Reusable Prompt Templates

Replace the bracketed placeholders with your own target.

Use twitter-autopilot to retrieve @[account]’s profile with bio, followers, URL, and retrieval time.

Use twitter-autopilot to retrieve @[account]’s latest [number] posts with types, times, URLs, and metrics.

Use twitter-autopilot to search [number] days of popular [keyword] posts; merge duplicates and report scope.

Use twitter-autopilot to search [number] days of [brand] mentions; classify sentiment and link examples.

Use twitter-autopilot to compare three accounts over [number] days; separate facts, responses, and interpretation.

Use twitter-autopilot to shortlist [number] [field] creators from bios and recent posts. Do not contact them.

Use twitter-autopilot to read [URL] with context, replies, and quotes; summarize both sides and gaps.

Use twitter-autopilot to publish this text exactly: [content]. Return the URL or explain the failure.

Use twitter-autopilot to publish the attached image with [caption]. Return the URL or explain the failure.

Use twitter-autopilot to follow @[account] and like the latest post. Return both URLs after success.

Usage note

Read keys only from secure local storage. Identify exact write targets and check the API response. Preserve source links and sample boundaries.
