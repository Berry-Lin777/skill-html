制作你的第一张二维码电子名片

这里用虚拟人物 Emma Wilson 做示范。跟着四步操作，你会得到一张可以直接分享、也能扫码保存联系人的电子名片。

本次使用：Claude Code联系人格式：vCard 3.0名片样式：midnight · square最终目录：emma-wilson-vcard
开始前，先购买并下载 QR Life Kit。解压后，用你自己的 Agent 打开文件夹即可。整个过程在本地完成，不需要配置 API Key。
这是一份自助操作指南，不构成法律意见，也不保证所有手机的扫码表现完全一致。二维码中的联系人信息任何拿到图片的人都能读取，请只放入你愿意公开的内容。
你会完成这四步
  1. 01准备信息并发给 Agent一次说清人物与用途
  2. 02让 Agent 构建并验证等待真实生成结果
  3. 03检查验证与信息边界确认两项扫码测试
  4. 04下载最终交付物card.png 与 qr.svg
  5. —后续修改与重跑围绕输出目录操作
01

先把需求一次说清楚

作用
把人物资料、联系方式和风格放在同一条消息里，后面就不用来回补信息。
你做什么
  1. 用 Agent 打开已下载的 Skill 文件夹
  2. 新建对话，粘贴下面的白话需求
  3. 把示例信息换成你自己的信息

03

确认二维码真的能扫

作用
确认裸二维码和名片上的二维码都能读出同一份联系人信息。
你做什么
  1. 打开输出目录里的 verification.json
  2. 确认总状态与两项测试均为通过
  3. 用手机再扫一次 card.png 做实际检查
复制这段发给 Agent

快速修改

  • 小改文案或样式：告诉 Agent 要改的具体字段，并要求输出到一个新的目录。
  • 不要直接在二维码上加 Logo、渐变或装饰覆盖；品牌视觉应放在二维码周围。
  • 邮箱、联系人和社交信息并未加密，修改前先确认哪些内容可以公开。

只重跑改动部分

请保留 Emma Wilson 的联系人内容，只把名片主题改为 paper，并输出到 C:\Users\LENOVO\emma-wilson-vcard-paper\。完成后重新验证 raw_qr 和 card_png。

从头再做一版

  1. 保留旧的 emma-wilson-vcard 目录作为备份。
  2. 新建 Agent 对话，重新发送步骤 01 的完整需求。
  3. 指定一个全新的输出目录；Skill 不会覆盖已有输出目录。
  4. 重新检查 verification.json，再交付新成品。
