Limits & dependencies

What this benchmark does not hide.

The package is ready to generate a trial, but production confidence depends on observing the artwork itself.

Public CDN dependency The default viewer loads p5.js from a public CDN, so it is not fully offline and requires network access on first load.
Template is intentionally incomplete The bundled viewer and generator are foundations. Their placeholder algorithm sections are expected to be replaced per artwork.
Visual quality needs human judgment Syntax and structure cannot prove originality, composition, conceptual depth, or the absence of accidental resemblance.
Performance is artwork-dependent Particle counts, animation loops, and canvas complexity must be profiled in the actual generated implementation.
