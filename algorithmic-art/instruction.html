01 / FIT

When the idea needs behavior.

Use the Skill when the visual should emerge from rules, forces, fields, repetition, or controlled chance—not when a fixed composition is already fully specified.

Strong fit

  • Generative and algorithmic artwork
  • Flow fields, particles, recursive systems, and organic growth
  • Reproducible editions that change by seed
  • Art that benefits from interactive parameter exploration

Choose another tool

  • Pixel-perfect reproduction of an existing artist’s work
  • Conventional photo editing or image retouching
  • A static logo with no computational behavior
  • Offline-only delivery without replacing the p5.js CDN dependency
02 / METHOD

From premise to living code.

The Skill separates the artistic thesis from implementation so that every control, force, and visual relationship has a reason to exist.

1

Read the signal

Find the subtle conceptual thread in the request without turning it into a literal illustration.

2

Name the movement

Write a concise, four-to-six paragraph algorithmic philosophy grounded in emergence and mathematical relationships.

3

Build the system

Express the philosophy in p5.js using seeded randomness, carefully tuned behavior, and an original algorithm.

4

Open exploration

Connect essential parameters, seed navigation, regeneration, reset, and PNG export in the required viewer structure.

03 / INPUT

Brief the feeling. Leave room for emergence.

A useful request supplies a conceptual seed, the desired behavior or atmosphere, and any practical constraints. It does not need to prescribe an algorithm.

Include what matters

Describe the idea, intended emotional register, whether the work should evolve or settle, and any palette or delivery needs. Mention a subject as reference material, not an artist to imitate.

04 / DELIVERY

A thesis, an engine, an edition.

The output is designed to remain understandable and explorable: the written intent explains the system, while the artifact makes its variations tangible.

.MD

Algorithmic philosophy

A named computational movement describing its processes, relationships, evolution, and aesthetic logic.

.HTML

Interactive viewer

.JS / PNG

Code and captures

The generative logic can be delivered as source, while the viewer supports exporting selected seed results as PNG.

05 / CONDITIONS

What the system relies on.

The Skill is intentionally opinionated about reproducibility, originality, and its viewer foundation. These boundaries are part of the product.

Primary runtime p5.js 1.7.0 loaded from a public CDN
Connectivity The generated viewer expects browser access to the p5.js CDN. Offline use requires packaging that dependency separately.
Reproducibility Both randomSeed() and noiseSeed() must receive the current seed before the system is initialized.
Viewer contract The bundled viewer structure, seed controls, actions, and interface branding remain fixed; the algorithm and meaningful parameters are the creative surface.
Originality Create an original computational language. Do not copy a living or identifiable artist’s signature style.
Performance Particle counts and expensive calculations should be tuned for smooth browser execution; complexity is not a substitute for composition.
