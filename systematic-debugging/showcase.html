Trace the boundary chain

Each observation answers one question, then moves one caller upstream. No speculative fix is introduced.

Observed effect

git init executes inside the package source directory.

Immediate call

The operation receives cwd: projectDir.

Bad value

projectDir is an empty string, so the current process directory is used.

Caller boundary

Session.create() was passed an empty context.tempDir.

Original trigger

Test setup read the value before beforeEach initialized it.

The evidence-backed handoff

The output separates the root cause from the implementation work that follows.

Root-cause statement

Eager access to uninitialized test context supplied an empty working directory.

The Git command behaved consistently with its input. The defect originated earlier in the lifecycle: setup state was consumed before initialization, allowing an empty path to reach the workspace layer.

Next actions
  1. Create the smallest failing reproduction.
  2. Guard access to the value before setup.
  3. Apply one source-level fix.
  4. Run the focused test, full suite, and pollution check.

Make recurrence harder

After the source fix is identified, the bundled reference recommends defense at every boundary.

Entry Reject empty or invalid working directories at the API boundary.
Business logic Require a meaningful project path before workspace initialization.
Environment Refuse unsafe Git initialization locations during tests.
Forensics Capture directory, process context, and call stack before the operation.
