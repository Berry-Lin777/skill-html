Short Drama Skill Tutorial

Eastern Beauty Director Skill


1. Basic Use

AccessOpen the Skill page and confirm Eastern Beauty Director is available.

DescribeProvide the character, scene, visible action, style, props, and aspect ratio. Short drama defaults to 9:16.

ReceiveGet locked parameters, visual direction, a main prompt, negative prompt, and production notes.

GenerateCopy the prompts into Jimeng or another image tool, then keep the best result as the character reference.

2. Skill Positioning

What it doesTurns a story brief into consistent visual direction, character rules, key-frame prompts, and negative constraints.

Delivery boundaryCovers image and image-to-video preparation—not screenplay writing, editing, voice-over, subtitles, or final production.

4. Input Fields and Invocation Format

Field

How to Fill

Purpose

Skill

Choose the main route, such as Modern Eastern Beauty, Eastern Fantasy Gu Feng, Classical Eastern Beauty, or Eastern Aesthetic Atlas.

Determines the main style route.

Style

Specify a concrete visual route, such as New-Chinese Magazine, Rainy Taxi Window, Song Tea Shadow, or Phoenix Palace Fire.

Controls visual tone, setting, lighting, and costume direction.

Temperament

Use one or two character temperaments, such as calm, gentle, cold, heroic, noble, or distant.

Controls facial expression, posture, and social distance.

Scene

Describe place, weather, time, and spatial layers.

The more concrete the scene, the more stable the image.

Costume

Describe silhouette, material, color, and details.

If omitted, the skill infers it from the route.

Action

Describe a visible action happening in the image.

The action should be visual, not only emotional.

Composition

Specify close-up, half body, thigh-up, full body, overhead, low angle, etc.

If ratio is omitted, the default is 9:16.

Generate

Use yes or no.

Yes means generate an image after prompt assembly; if omitted, the skill returns the prompt first.

Character identity

Main character, antagonist, companion, rescuer, goddess, scholar, doctor, etc.

Turns the subject into a role, not a generic portrait.

Props

Name important objects and their functions.

Props should serve action and story.

Color palette

Specify dominant color, supporting color, and accent color.

Keeps series visuals consistent.

Aspect ratio

Use 9:16, 3:4, 2:3, 16:9, etc.

Horizontal output must explicitly state 16:9.

Platform

Jimeng, Midjourney, Stable Diffusion, ComfyUI, etc.

Affects prompt language and parameter expression.

Must keep

List characters, props, scene elements, or ratios that cannot change.

Maintains continuity and project consistency.

Must avoid

List unwanted visual problems or style deviations.

Expands the negative prompt.

8. Route Selection Rules

- Choose Eastern Fantasy Gu Feng when the request includes mythology, xianxia-adjacent elements, ritual artifacts, palace ritual, or supernatural spectacle.

- Choose Classical Eastern Beauty when the setting is ancient but does not require magic, mythology, or impossible spectacle.

- Choose Modern Eastern Beauty for realistic, modern, magazine, new-Chinese, qipao cinematic, or urban scenes.

- Choose Convention Character Photography for convention, game booth, original cosplay role, or official booth photography.

- Choose Gu Feng Girlfriends when the relationship between two adult ancient Chinese women is the focus.

- Choose Sweet Pure Lifestyle Portrait for modern lifestyle, candid feeling, girlfriend perspective, street, bookstore, cafe, or convenience-store scenes.

- Choose Eastern Aesthetic Atlas when the output is a cover, character page, overview page, cultural card, or museum-catalog layout.

10. Plot Setting Rules

For short drama use, each key image should be tied to a plot beat. The skill turns the plot beat into a story moment, action chain, gaze target, and visual priority.

- Write what just happened, what is happening now, and what may happen next.

- The action chain should be visible: pulling a curtain, supporting a companion, gripping a prop, turning toward a door, etc.

- The gaze target should be clear: window, prop, companion, off-screen threat, or camera.

- World details should serve the plot: weather, light source, spatial layers, key objects, background state.

- Use only one main conflict and one main visual hook per image.

11. Visual Image Rules

Rule

How to Write

Purpose

Subject first

Write identity, facial temperament, posture, and action before the scene.

Prevents the image from becoming an empty environment.

One visual hook

Keep only one strongest first-glance attraction point.

Avoids decorative clutter.

Clear props

Props should have a function, not just decoration.

Reduces prop deformation and semantic loss.

Spatial layers

Give the foreground, midground, and background distinct functions.

Improves depth.

Motivated light

Name key light, fill light, and rim light sources.

Avoids random lighting effects.

Controlled color

Limit dominant, supporting, and accent colors.

Maintains premium feeling and series consistency.

17. Jimeng Handoff Workflow

- First use the skill to output character visual settings and a single key-frame prompt.

- Generate the first frame in Jimeng with the Chinese main prompt. For vertical short drama, use 9:16 unless the project states otherwise.

- Select the most stable image for face, costume, and props as the character reference.

- Repeat character lock items in later shot prompts, such as hairstyle, costume, key props, and color palette.

- For image-to-video, add one main motion direction, such as rain movement, subtle light movement, or a slow character turn.

- If the character drifts, reduce scene complexity first, then strengthen character lock and negative prompt.

18. Common Mistakes and Fixes

Mistake

Problem

Fix

Only writing a theme and beauty

Character, plot, action, and scene are too vague; output becomes a generic portrait.

Add role identity, action chain, props, light source, and aspect ratio.

Not specifying vertical or horizontal

The skill defaults to 9:16, which may not match the delivery format.

Write 9:16 or 16:9 in the composition field.

All characters have the same temperament

Multi-character images may produce repeated faces and weak recognition.

Lock different face shapes, hairstyles, costumes, temperaments, and props.

Only using generic prop names

The model may create vague objects.

Write the exact prop name and function.

Overloading the image with elements

The subject becomes unclear and the key frame is not usable.

Keep one main conflict and one visual hook per image.

Negative prompt is too generic

Hands, face, props, and style deviations remain uncontrolled.

Write exclusions by anatomy, hands and feet, face, props, and style.
