01

Download the Skill ZIP

Purpose
Get an installable package for remotion-editing-styles.
What you do
  1. Open the download page.
  2. Download the ZIP package.
  3. Do not change the package structure.

https://finchip.ai/skills/remotion-editing-styles-finchip
02

Send it to the workspace and install

Purpose
Give your Agent access to the package, then use skill-installer to install the Skill.
What you do
  1. Drag the ZIP package into the current workspace.
  2. Ask your Agent to unzip it and inspect SKILL.md.
  3. Ask your Agent to install the Skill with skill-installer.
Send this to your Agent
I have sent the remotion-editing-styles ZIP package to the current workspace. Please unzip it and inspect SKILL.md first, then use skill-installer to install this Skill. When installation is complete, tell me the Skill name, installation path, and the source footage you need next.
Do not begin the edit until installation is complete. Uploading the ZIP alone does not install the Skill.
03

Prepare and name the footage

Purpose
Organise source clips into files that your Agent can identify and use in the intended order.
What you do
  1. Create separate Sydney/ and Melbourne/ folders.
  2. Name the Sydney clips coastline, ocean, and zoo.
  3. Name the Melbourne clips dogs, flower shop, and ocean.
  4. Place both organised folders in the current workspace.
Keep names short, clear, and tied to the scene or playback order. Avoid vague names such as “new-video-1” or “final-version-2.”
04

Describe the editing requirements

Purpose
Tell your Agent the footage, goal, video style, format, audio treatment, and final deliverables in one request.
What you do
  1. Enter the source folder and describe the footage.
  2. Set the goal, audience, and one dominant style.
  3. Specify ratio, duration, codec, and audio treatment.
  4. Confirm cropping or background fill before any ratio conversion.
Send this to your Agent
Use remotion-editing-styles to edit the videos in [source folder].
Footage: [Sydney ocean, coastline, and zoo / Melbourne flower shop, beach dogs, and coast].
Goal: Create a [travel / lifestyle] short video for [audience].
Style: [Xiaohongshu Illustrated Poster / Relaxed Handwritten Poster / one dominant style].
Video format: [16:9 or 9:16], approximately [duration] seconds, export an H.264 MP4.
Audio: [preserve original audio / use licensed background music].
First inspect the source ratio, duration, and audio tracks. If a ratio conversion is needed, explain the crop or background-fill approach and wait for confirmation.
Then create an edit plan, an editable Remotion project, three preview stills, and the final MP4.
05

Review the finished edit

Purpose
Confirm that the Agent validated the plan, created the editable project, rendered preview stills, and exported the final MP4.
What you do
  1. Review the Agent's run result.
  2. Open the project's out folder to find the finished video.
  3. Play the MP4 and check subject placement, captions, audio, duration, and ratio.
Send this to your Agent
When the run is complete, tell me whether the edit plan passed validation, whether the project is editable, and the final MP4 dimensions, duration, and frame rate. List every deliverable path and render opening, middle, and ending preview stills for my review.

Final review checklist

  • The final MP4 plays correctly and matches the requested ratio.
  • The subject is not cropped, captions do not overflow, and audio matches the brief.
  • Keep the editable project, edit plan, and three preview stills—do not keep the MP4 alone.
