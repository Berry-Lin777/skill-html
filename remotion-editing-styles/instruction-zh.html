01

下载 Skill 压缩包

作用
获取可安装的 remotion-editing-styles Skill 包。
你做什么
  1. 打开下载页。
  2. 下载 ZIP 压缩包。
  3. 不要修改压缩包内的文件结构。
下载链接
https://finchip.ai/skills/remotion-editing-styles-finchip
02

发送到工作区并安装

作用
让你的 Agent 读取压缩包，并用 skill-installer 将 Skill 安装到技能目录。
你做什么
  1. 把 ZIP 压缩包拖入当前工作区。
  2. 让 Agent 解压并检查 SKILL.md。
  3. 让 Agent 使用 skill-installer 安装该 Skill。
发给 Agent 的原文
我已把 remotion-editing-styles 的压缩包发送到当前工作区。请先解压并检查 SKILL.md，然后使用 skill-installer 安装这个 Skill。安装完成后告诉我 Skill 名称、安装位置和下一步需要的素材。
安装完成后再开始剪辑。只把压缩包放在工作区并不等于已安装。
03

准备并命名视频素材

作用
把视频素材整理成 Agent 能准确识别和按顺序使用的文件。
你做什么
  1. 请为“模特时尚短片”和“演唱会宣传”分别建立独立的素材文件夹。
  2. 按镜头内容命名模特素材，例如 户外1.mp4、户外2.mp4、室内.mp4。
  3. 演唱会宣传素材可按内容命名为 灯光.mp4、歌曲1.mp4、歌曲2.mp4、谢幕.mp4。
  4. 把整理好的素材文件夹放进当前工作区。
命名应简短、明确，并与镜头内容或播放顺序对应。不要使用“新建视频1”“最终版2”等难以识别的名称。
04

填写剪辑要求

作用
一次告诉 Agent 素材内容、目标、视频风格、格式、声音和最终交付要求。
你做什么
  1. 填写素材文件夹和素材内容。
  2. 确定目标、受众与一个主导风格。
  3. 填写视频比例、时长、编码和音频要求。
  4. 如需转换画幅，先确认裁切或背景填充方式。
发给 Agent 的原文
请使用 remotion-editing-styles 编辑 [素材文件夹] 中的视频。
素材内容：[户外1、户外2、室内三段模特镜头 / 灯光、歌曲1、歌曲2、谢幕四段演唱会镜头]。
目标：制作一条 [时尚编辑短片 / 演唱会宣传片]，面向 [受众]。
视频风格：[Natural Retro Geometric / Cyber Brutalism]。
视频格式：[3:4 竖屏 / 4:3 横屏]，时长约 [秒数]，导出 H.264 MP4。
音频要求：[使用已授权背景音乐 / 保留演唱会现场原声]。
请先检查素材比例、时长和音轨；如需转换画幅，请先说明裁切或背景填充方案并等待确认。
然后创建 edit plan、可编辑 Remotion 项目、预览帧和最终 MP4。
05

检查剪辑完成的视频

作用
确认 Agent 已完成方案校验、项目生成、预览帧和最终 MP4 渲染。
你做什么
  1. 查看 Agent 返回的运行结果。
  2. 进入项目的 out 文件夹找到成片。
  3. 播放最终 MP4，检查主体、字幕、声音、时长与比例。
发给 Agent 的原文
请完成运行后告诉我：edit plan 是否通过校验、项目是否可编辑、最终 MP4 的尺寸/时长/帧率，以及所有交付文件路径。请同时渲染开头、中段、结尾预览图，供我检查。
