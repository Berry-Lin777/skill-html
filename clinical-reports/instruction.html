Recommended prompt

Using Clinical Reports, create a CARE 2013 case-report draft from the attached synthetic source-fact manifest.

Keep unsupported fields null, preserve every fact ID, run the provenance and case-report validators, and return:
1. the draft JSON,
2. unresolved fields,
3. validator results,
4. required human reviewers.

Do not infer clinical content or authorize submission.

Input gate

  • Explicit reporting purpose
  • Allowed data classification
  • Documented authority
  • Minimum-necessary fields
  • Verified provenance
  • Named review owner

Deliverables

Files a reviewer can inspect.

report-draft.json

A visibly blocked draft structure populated only from supported facts.

provenance-manifest.json

Fact-to-claim linkage, verification metadata, and source value hashes.

validator-result.json

Errors, warnings, missing requirements, and review-required status.

handoff-summary.md

Guidance version, unresolved fields, limitations, and named reviewer roles.

Non-negotiable boundary

Structure and evidence—not clinical authority.

Use only local synthetic, properly deidentified, or aggregate material. The skill does not diagnose, interpret patient data, decide reportability, sign, file, transmit, or certify compliance.
