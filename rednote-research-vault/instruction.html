Built for research archives, not casual scraping.

Use it when a RedNote post must survive as evidence: what was on the page, what media belonged to it, and what can safely sync to a table.

Strong fit

  • Competitive content research and benchmarking
  • Creator / growth teams archiving public share links
  • Video and image notes that need local media + metadata
  • Feishu/Lark Base upsert with Note ID dedupe
  • Agents that must report gated or incomplete fields honestly

Not the right tool

  • Bypassing CAPTCHA, login walls, or private notes
  • Promising anonymous access for every link
  • Bulk scraping without user authorization
  • Uploading media to Base unless separately requested
  • Inventing missing engagement counts or captions

Four modes. One evidence contract.

Pick the smallest action that answers the request. Cloud writes stay behind an explicit confirmation gate.

01 · INSPECT

Metadata only

Capture without --download-media and return the normalized summary.

02 · ARCHIVE

Local evidence

Download allowlisted media, write record.json, then run the validator.

03 · SYNC

Base upsert

Dry-run the field map first; --commit only after user confirmation.

04 · ANALYZE

Separate notes

Write analysis beside the bundle. Never rewrite platform fields in place.

Inputs that keep capture honest.

Prefer a complete share URL with xsec_token. If the page is challenged, refresh the link, use an authorized cookie through REDNOTE_COOKIE, or provide a saved HTML snapshot.

What you get back.

Each successful archive creates a new timestamped bundle. Tokens are redacted from stored URLs by default.

HTML

source.html

Immutable page snapshot with byte size and SHA-256.

JSON

record.json

Normalized note, metrics, media candidates, fingerprint.

MD

record.md

Human-readable summary for quick review.

MEDIA

media/*

Downloaded images/video/subtitles with local hashes.

QA

validate_bundle.py

Structural checks plus media_archive completeness.

BASE

Optional upsert

Idempotent Note ID sync after dry-run confirmation.

Dependencies

Python 3 standard library only for capture, validation, and Feishu sync scripts. Feishu credentials are injected at runtime and never stored in the skill.

Safety boundary

Passing validation proves bundle integrity, not lawful access or copyright clearance. Approximate metrics such as 10+ stay in metrics_raw and are never coerced into exact integers.
